# ارزیابی پیش‌نیازهای ریاضی ۱ دهم تجربی

مجموعهٔ آزمون‌های تشخیصی کوتاه برای سنجش آمادگی دانش‌آموز قبل از شروع کتاب ریاضی ۱ دهم (رشتهٔ تجربی).

هدف، نمرهٔ رسمی نیست؛ پیدا کردن نقطهٔ شروع مناسب و مهارت‌هایی است که به تمرین یا آموزش از پایه نیاز دارند.

## چطور استفاده کنم؟

1. فایل `index.html` را با مرورگر باز کن (یا همین صفحهٔ GitHub Pages).
2. یکی از ایستگاه‌ها (فصل‌ها) را انتخاب کن و آزمون را انجام بده.
3. در پایان، فایل نتیجه به‌صورت خودکار دانلود می‌شود.
4. همان فایل را برای معلم یا مسئول آزمون بفرست یا نگه دار.

همه‌چیز **آفلاین** کار می‌کند؛ بعد از بارگذاری اولیه نیازی به اینترنت نیست. فایل نتیجه هم مستقل و قابل‌بایگانی است.

## ایستگاه‌ها

| فصل | موضوع |
|-----|--------|
| ۱ | عدد و محاسبات پایه |
| ۲ | عبارت‌های جبری |
| ۳ | معادله و نامعادله |
| ۴ | مختصات و پیش‌نیازهای تابع |
| ۵ | هندسه و پیش‌نیازهای مثلثات |
| ۶ | مجموعه، الگو و دنباله |
| ۷ | شمارش، آمار و احتمال |

هر ایستگاه مستقل است؛ می‌توان به هر ترتیبی انجام داد.
